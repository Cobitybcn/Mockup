# Archivo histórico

Documentos retirados de circulación el 2026-08-03. **Ninguno tiene autoridad.**

Se conservan porque registran cómo se llegó hasta acá, no cómo funciona el sistema hoy.
Varios se declaran a sí mismos "vigentes", "fuente de verdad" o "no modificar": esas
declaraciones caducaron. Algunos describen arquitecturas que producción ya abandonó
(SQLite local, flujos de mockups retirados) y citan archivos que ya no existen.

Para saber qué hace el sistema hoy: `ACTA_DE_CIMIENTOS.md` en la raíz, y sobre todo
`platform/tests/`, que es lo único que se verifica en cada despliegue.

Motivo del retiro: una auditoría del 2026-08-03 confirmó que ningún código, test ni
script vivo los referencia, y que se contradicen entre sí y con el sistema real.
